Genbeya builds the kit on `develop` (GENBEYA-68, merged 2026-11-25) and releases it with 0.2.1. Its protocol differs from this app's kit: see [[Upstream#genbeya-s-kit-and-this-app-s]]. Until then `tool/build_kit` builds the same bundle from Genbeya's sources ([[GM-3]]), so nothing in the app waits for this (D2 in [[Decisions]]).

- [x] `tool/build_kit` downloads `genbeya-kit-<version>.zip` of the release pinned in `kit/GENBEYA_KIT` (its SHA-256 too) and checks every file against its `manifest.json`, the protocol, and that it comes from `kit/GENBEYA_REF`
- [x] The app refuses a kit whose `protocol` on `ready` it doesn't speak (`KitHost._start`), and the build refuses one whose manifest names another
- [x] Remove `kit/src/` once Genbeya's `src/shells/kit/` replaces it; keep the source build for the nightly job against `develop` (`build.mjs --source develop`, then `test.mjs`)
- [x] Note the Genbeya version in [[Upstream]]
- [x] Meanwhile, once `v0.2.0` is tagged (planning and pull requests released): pin `kit/GENBEYA_REF` to it, rebuild the kit, regenerate the conformance cases and make the Dart side pass (2026-11-25: `5739e1a`; all 1,371 cases unchanged, the kit's 26 checks pass)
- [x] Genbeya's kit gains `outline`, `reveal` and the `checkboxes` field of a Markdown preview ([[Kit additions]]; shipped in 0.2.1)
- [x] The host speaks Genbeya's message fields: `theme.mode` and tokens without `--`, the `wiki`, `settings` and `plan` parts as Genbeya sends them, `readOnly` always

Built (2026-11-26): the app ships Genbeya 0.2.1's kit. `tool/build_kit/test.mjs` passes its 26 checks against it with the app's messages. Two behaviours differ from the app's former kit: toolbar steps join with recent typing in the undo history (asked of Genbeya, [[Kit additions#4-toolbar-steps-are-their-own-undo-steps]]), and the editor reports clean once it sent `save` (the edit screen keeps a failed save unsaved). To try on the phone: every screen with the kit (a wiki page with diagrams, **On this page** and a `[[Page#heading]]` link, a task's description and comments, **Edit** with `[[` and `@`, a checkbox in a page and in a task), in light and dark.
