A test for every user story that is built, following its steps on the app's real screens, so that a story that worked keeps working ([[User stories]]). Found necessary when Today didn't follow an edit made just before ([[GM-14]]): the screen's own tests checked what it showed when opened, not what it did when the repository changed.

- [x] A harness (`test/stories/support/`): one clone in memory behind the real screens, managers and providers; a Git fake that plays the remote (branches, upstreams, refused pushes); a stand-in for the kit that sends what the kit would
- [x] A widget test per built story, named after it (`test/stories/us_<n>_…_test.dart`): US-2, US-4, US-5, US-6, US-8, US-9, US-10, US-11, US-12, US-14, US-24, US-25, US-26
- [x] Stories that need the real Git core keep their end-to-end tests, named after the story: US-1 (SSH, `native/genbeya_core/tests/flows.rs`), US-22 and US-23 (`test/sync_flow_test.dart`)
- [x] [[User stories]] names the test of each story; [[Development]] says how to add one
- [ ] Later, in a job of its own: integration tests on an Android emulator for what only the real app wires together (clone and sync through the core, a checkbox in the real kit, shared text from another app)

Built (2026-11-26): 13 story files, 22 tests (`test/stories/`), all passing on their first or second run; the second runs were mistakes in the tests (a fixture's free ID, the test screen's width), not in the app. The emulator tests stay open here.
