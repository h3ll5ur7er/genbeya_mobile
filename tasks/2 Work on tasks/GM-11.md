How mobile edits reach everyone, without ever losing one. See [[Architecture#where-edits-go]] and [[Experience#sync-and-changes]].

- [ ] Every save is a commit named after the change and the task, with the repository's identity
- [ ] Where commits go, chosen on the first edit: content branch, checked-out branch, or `mobile/<handle>`
- [ ] Sync: fetch, rebase, push, one at a time per repository; pull to refresh; optional automatic sync
- [ ] Genbeya merge for task and pull request files: frontmatter per key, signed lines from both sides; conformance cases for it
- [ ] Rescue branch when it still conflicts, with a clear message of what differs
- [ ] **Changes**: unsynced commits, undo the last ones before they are pushed
