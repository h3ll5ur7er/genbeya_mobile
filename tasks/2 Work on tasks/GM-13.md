Answer a comment as easily as in a chat app, in Genbeya's format. See [[Experience#tasks]].

- [x] A native text field above the keyboard (D4); `@`, `//` and `[[` pickers from the app: offered while typing as desktop's editor offers them, and as buttons (`lib/managers/suggestions.dart`, conformance kinds `suggest.mentions`, `suggest.references`, `suggest.dates`)
- [x] Signed with the Git name and the local time with its offset, exactly as `task-comments.ts` writes it; headings in the text protected with `\`
- [x] Edit and delete your own comments (desktop's rule: the comment's author is the clone's Git name)
- [x] Conformance cases: append, edit, delete (`task.comment`, 63 cases); a comment written on two branches keeps both in time order (`test/sync_flow_test.dart`, through the core)

Built (2026-11-25): `TaskWriter.addComment`, `editComment`, `deleteComment` write as desktop's content manager does (`Comment on <ID>`, `Edit a comment on <ID>`, `Delete a comment on <ID>`): adding needs no version, since comments go last; editing and deleting name a comment in the version shown, and only one's own. The composer sits under the task; the kit renders every comment, and one's own are listed under it with **Edit** and **Delete**. The cases found a desktop slip with the wiki at the root ([[Upstream]]).

To try on the phone: comment on a task with `@` (type it, or the button), `[[` (a task, a page, a file) and `//` (tomorrow, `fri`, `3d`, a calendar); edit and delete it; sync and look at the file on desktop, then comment on desktop and on the phone on the same task before syncing.
