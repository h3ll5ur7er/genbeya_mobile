Repositories that keep tasks, wiki, settings or pull requests on Genbeya's content branch work as on desktop. See [[Architecture#clones-on-a-phone]].

- [x] Fetch the content branch with the code branch; read each area where `.genbeya-content` says
- [x] Edits to an area on the branch are committed onto it without a checkout
- [x] Sync rebases and pushes the content branch too
- [x] Tested against a repository whose layout was made by Genbeya desktop

The three behaviours were built with [[GM-11]] (story test `test/stories/us_25_content_branch_test.dart`). The check against desktop: `tool/conformance/desktop-repository.ts` lays a repository out with desktop's own `ContentStore` at the pinned Genbeya commit, and `test/desktop_layout_test.dart` runs the phone's Git core on it (see [[Architecture#conformance]]).
