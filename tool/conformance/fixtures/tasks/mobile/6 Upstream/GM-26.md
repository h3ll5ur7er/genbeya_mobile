For the release: screenshots and photos in tasks and pull requests, as [[Attached images]] specifies (D8 in [[Decisions]]). Waits for Genbeya to ship the spec. Task images would already render on desktop, but wait so the format is agreed first; pull request images must wait for Genbeya's change ID rule, or every approval would look stale on desktop.

- [ ] **Photo** in a task's description and comments: `tasks/.images/<ID>/`, linked from the root, named and processed as the spec says
- [ ] **Photo** in pull request replies and code range comments: `pulls/.images/<ID>/`, only with a Genbeya release whose change ID leaves them out
- [ ] Change ID: the spec's excludes, with conformance cases against the desktop
- [ ] Deleting a task takes its images along
- [ ] Conformance cases: names, folders and references as Genbeya writes them
- [ ] Note the Genbeya version in [[Upstream]]
