# Genbeya Mobile

A trial mobile client for [Genbeya](https://github.com/genbeya/genbeya), in Flutter for Android and iOS: the wiki, the task board, pull requests and a small code editor for a Git repository cloned on the phone, in the same plain files the desktop app reads and writes.

**Status:** planning. There is no code yet. The plan is this repository's own Genbeya wiki and board:

- [Home](docs/Home.md): why a mobile client, and its principles
- [Experience](docs/Experience.md): what the app does, screen by screen
- [Architecture](docs/Architecture.md): Flutter, a Rust Git core, Genbeya's renderer reused in a WebView, and conformance checks against the desktop
- [Roadmap](docs/Roadmap.md): milestones, risks, how the trial is judged
- [Tasks](tasks/): the backlog, one Markdown file per task

Open this folder in Genbeya to see the plan with live references, the board and the timeline.
